Rubik's Cube 3D

Tournez les faces du cube avec les boutons ou utilisez les touches du clavier (U, R, F, D, L, B)

Contrôles 🎯

Faces Principales

Tranches du Milieu

Actions

Comment utiliser :

  • Boutons : Cliquez sur les boutons pour tourner les faces
  • Clavier : Utilisez les touches U, R, F, D, L, B (majuscule/minuscule)
  • Souris/Tactile : Cliquez/touchez une face pour la tourner
  • Rotation libre : Cliquez et faites glisser pour tourner la vue
  • Zoom : Utilisez la molette de la souris ou pincez

Notation : U = Up (haut), D = Down (bas), R = Right (droite), L = Left (gauche), F = Front (avant), B = Back (arrière), M = Middle (milieu), E = Equator (équateur), S = Standing (debout)

Apostrophe (') : Indique un mouvement inverse (anti-horaire)
